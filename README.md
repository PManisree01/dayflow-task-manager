# DayFlow — Personal Planner

DayFlow is a browser-based personal productivity application designed to help users organise daily tasks, manage schedules, track habits, and monitor their progress.

## Features
- Daily task management
- Daily schedule organisation
- Habit tracking
- Productivity analytics
- Reminders
- Browser-based local data storage

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start organising your daily activities.

## Project Goal
To create a simple and accessible productivity tool that helps users manage everyday activities in one place.
